# station: гара с каса

Продава три вида билети (S еднократен, D дневен, M месечен), валидира, проверява, прави отчет и го записва в `report.txt`.
Програмата работи. Въпросът в час е какво не ти харесва в нея и защо.

`Scenario1`–`Scenario4`: четири сценария от лист 1. Първо предскажи какво ще излезе, после пусни.

```
javac *.java
java Main
java Scenario1
```
