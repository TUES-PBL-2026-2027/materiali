# ООП, 11 клас, ТУЕС, 2026/27: материали

Тук са материалите за всеки час, подредени по учебните седмици на курса: LW01 е 28.09–2.10.2026, LW02 е 5–9.10, LW03 е 12–16.10; седмицата 19–23.10 е без часове, LW04 е 26–30.10.

- `LWNN/1T/`: първият час на седмицата · `LWNN/2P/`: вторият
- във всяка: `files/`: кодът за копиране
- презентациите не са тук: те са в Classroom

Кодът в `files/` е за копиране в твоята папка `oop`. Някои файлове нарочно не се компилират: това е задачата.

Веднъж, в `Documents`:

```
git clone https://github.com/TUES-PBL-2026-2027/materiali.git
```

Всяка седмица, в `materiali`: `git pull`. Файлът се копира от папката `oop`, например:

```
cp ../materiali/LW01/2P/files/Arrays1.java .
```
